# Política de Segurança

O **My-Memory** é uma engine de memória local desenvolvida com foco em privacidade e segurança *local-first*.

---

## 🛡 Versões Suportadas

Apenas a versão mais recente na branch `main` recebe correções ativas de segurança:

| Versão | Suportada |
| :--- | :--- |
| `main` (latest) | :white_check_mark: |
| < 0.1.0 | :x: |

---

## 🔍 Reportando Vulnerabilidades

Se você identificar uma vulnerabilidade de segurança neste projeto, por favor **não abra uma issue pública**.

Em vez disso:
1. Abra um relatório através da funcionalidade de **Security Advisory Privada** do GitHub em:
   `https://github.com/FelipeMiiller/my-memory/security/advisories/new`
2. Ou entre em contato diretamente com o mantenedor através do perfil do GitHub [@FelipeMiiller](https://github.com/FelipeMiiller).

### O que incluir no reporte:
- Descrição da vulnerabilidade;
- Passos para reprodução ou Prova de Conceito (PoC);
- Potencial impacto para o usuário ou integridade do banco SQLite;
- Sugestão de mitigação (se aplicável).

Agradecemos e reconhecemos publicamente a comunidade de pesquisadores e desenvolvedores por contribuições responsáveis de segurança.
